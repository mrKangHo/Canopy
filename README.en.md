<h1 align="center">Canopy</h1>

<p align="center">
  A native macOS menu-bar app that plays looping nature footage from <a href="https://pixabay.com">Pixabay</a> as your actual desktop background — a live wallpaper, not a screensaver.
</p>

<p align="center">
  <img src="docs/screenshot.png" alt="Canopy Screenshot" width="800" />
</p>

## Features

- **Browse & play** — Nature/Backgrounds/Animals/Travel shelves plus free-text search
- **Per-display wallpapers** — pick a different video for each connected monitor or apply to All
- **My Collection** — videos you've played are saved automatically
- **True Retina rendering** — crisp 4K playback synced to screen backing scale
- **Battery-aware** — pauses automatically on screen lock, sleep, or Low Power Mode

## Installation

### Homebrew
```bash
brew tap mrKangHo/tap
brew install canopy
```

Or via direct tap:
```bash
brew tap mrKangHo/canopy https://github.com/mrKangHo/Canopy
brew install --cask canopy
```

## Requirements

- macOS 13.0 (Ventura) or later
- Free [Pixabay API key](https://pixabay.com/api/docs/)
